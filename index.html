Building operating systems with KernelCraft

    

      

        
Writing good prompts

        
    
          
  • Name your OS and its look: "called Nova, glassy dark theme with cyan accents".
    • 
          
  • List the apps you want: file explorer, notepad, paint, games, settings, a clock widget.
    • 
          
  • Describe behaviour: "the terminal supports pipes", "double-click files to open them".
    • 
          
  • Iterate: keep chatting. Every message changes your current OS, one feature at a time.
    • 
        

        
Targets

        
    
          
  • 16-bit: assembly, BIOS services, text or VGA graphics. Runs in the browser.
    • 
          
  • 32-bit: C on the KernelCraft SDK. Runs in the browser.
    • 
          
  • 64-bit: the same SDK in long mode. Verified in QEMU; export to run locally (the browser emulator is 32-bit only).
    • 
          
  • Linux Forge: a real Linux kernel plus BusyBox; the AI writes init scripts, config and C programs. Export a .tar.gz with a QEMU run script.
    • 
        

        
In the builder

        
    
          
  • Code tab: edit any file and press Run my edits to compile without AI.
    • 
          
  • Console tab: everything the OS logs with kc_log() (COM1).
    • 
          
  • Apps tab: describe any app for the AI to write, or add a ready-made browser, Paint, games, clock, calendar or piano.
    • 
          
  • ⚙ Settings (next to the send button): OS type, CPU cores, RAM up to 24 GB, graphics memory up to 6 GB, and screen resolution.
    • 
          
  • 🖱 captures the mouse for the guest; Esc releases it.
    • 
          
  • Inside SDK desktops: double-click icons, drag windows by the title bar, F1 opens the start menu, Alt+Tab cycles windows.
    • 
        

      

      

        
KernelCraft SDK quick reference


#include "kc.h"

/* A new app: icon on the desktop + start menu entry */
static void paint(kc_window *w, surface *s) {
    fill_rect(s, 0, 0, s->width, s->height, RGB(20, 24, 36));
    draw_text(s, 16, 16, "Hello from my app", RGB(255, 255, 255));
}
static void on_event(kc_window *w, kc_event *ev) {
    if (ev->type == EV_MOUSE_DOWN) { wm_notify("Clicked!"); wm_invalidate(w); }
}
static void hello_open(void) {
    kc_window *w = wm_create("Hello", -1, -1, 400, 240);
    w->on_paint = paint;
    w->on_event = on_event;
}
KC_APP(hello, "Hello", icon_info, hello_open);

/* A terminal command */
static void cmd_hi(int argc, char **argv, void (*print)(const char *)) {
    print("hi there\n");
}
KC_COMMAND(hi, "say hi", cmd_hi);

/* Startup code: theme, wallpaper, files */
static void setup(void) {
    theme.os_name = "Nova";
    theme.accent = RGB(0, 230, 255);
    fs_write("/home/user/welcome.txt", "Hi!\n", 4);
}
KC_BOOT_HOOK(setup);
